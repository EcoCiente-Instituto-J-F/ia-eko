- LangGraph: https://docs.langchain.com/oss/python/langgraph/
- MCP Python SDK v2: https://py.sdk.modelcontextprotocol.io/
- MCP Specification 2026-07-28: https://modelcontextprotocol.io/docs/2026-07-28/
- A2A Python SDK / migração v1.0: https://github.com/a2aproject/a2a-python/blob/main/docs/migrations/v1_0/README.md
- PyMongo Async API: https://www.mongodb.com/docs/languages/python/pymongo-driver/current/reference/migration/
- SINIR: https://sinir.gov.br/
